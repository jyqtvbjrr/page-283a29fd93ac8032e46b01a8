使用说明

SEC.01 / HOW TO
票据 A新用户上手
  1. 在套餐区块选定档位，完成订阅并保存好账户信息。
  2. 打开客户端区块，按设备下载对应客户端。
  3. 将订阅链接导入客户端，等待节点列表刷新完成。
  4. 选择节点并连接，确认状态正常后即可开始使用。

提示：订阅链接相当于你的账户钥匙，请勿转发给他人。

票据 B老用户速查
  1. 换设备：在新设备安装客户端，重新导入同一订阅链接。
  2. 节点异常：先在客户端内刷新订阅，再切换其他节点。
  3. 流量查询：以客户端或账户页显示的用量为准。
  4. 续费：到期前在原档位续费即可，配置无需改动。

提示：同时在线设备数受套餐限制，超出会被挤下线。

常见问题

SEC.04 / FAQ
问 · 01订阅之后多久可以开始使用？
答完成订阅并拿到订阅链接后，按使用说明的四步操作即可，导入客户端并刷新节点列表后就能连接。
问 · 02一个账号可以在几台设备上用？
答取决于套餐：基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。超出限制时，先连接的设备可能被挤下线。
问 · 03流量用完了怎么办？
答各档位流量按月结算：100GB / 300GB / 1000GB。用量以客户端或账户页显示为准，建议提前关注剩余量，必要时升级档位。
问 · 04节点连不上或速度慢，先做什么？
答按顺序排查：刷新订阅 → 切换节点 → 重启客户端。三步都无效时，旗舰版用户可提交优先工单。
问 · 05按月付和按年付有什么区别？
答权益完全相同，只是计费方式不同。按年付折算为 ¥150 / ¥350 / ¥850 每年，比按月付合计更低。
问 · 06团队版适合什么场景？
答适合多人共用或需要定制路由的场景：20 台设备同时在线、VIP 高带宽节点、企业定制路由，并配专属客户经理对接。
